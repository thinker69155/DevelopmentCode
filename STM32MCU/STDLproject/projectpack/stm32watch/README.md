项目名称：stm32手表    
开发环境：  
基于stm32f103c8t6，使用标准库进行开发  
#开发时间：  
创建于2026.2.14  于2026.2.24基本完成
  
#程序介绍：  
有基本的图形化UI可用于操作，实现基本的电子手表功能。  

外部电路：  
外设：stm32f103c8t6最小系统板，3枚按键，一块MPU6050，一块OLED显示屏幕，一个LED灯，若干导线   
连接：3枚按键——B12,13,14；LED灯——-接地，+接A1；OLED——SCL，SDA接B8,9；VB单独供电；MPU6050——SCL，SDA接B10,11  

问题：  
1.按下确认键后，会直接返回首页，而不是上一级菜单。  
2.MPU6050在姿态测算功能中并不显示。
